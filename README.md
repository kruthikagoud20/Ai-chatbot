# 🤖 AI Chatbot

A smart AI chatbot developed using Python Flask, HTML, CSS, and JavaScript.

## Features
- Interactive chatbot interface
- AI-based responses
- Flask backend integration
- Responsive UI design
- API communication using OpenRouter

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Run the project:
python app.py

3. Open browser:
http://127.0.0.1:5000
